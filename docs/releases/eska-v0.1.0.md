# ESKA v0.1.0

`eska-v0.1.0` is the first governed repository release of the Executable Semantic Knowledge Architecture.

## Permanent semantic identity

This release is the first repository snapshot governed under the permanent W3ID namespace:

```text
https://w3id.org/eska#
```

The provisional `urn:eska:core:` identifiers remain recorded only as historical predecessors in `model/namespace-migration.json`.

## Executable evidence

The governed release preserves the verified reference architecture covering seven executable-semantic modes, sixteen semantic Executions, generalized Knowledge Service and Knowledge Agent behavior, blue/green Deployment binding, five operational invocation lineages, and provenance/evidence lineage to immutable Pizza semantic sources.

The publication contract verifies five ontology modules and 53 declared ESKA terms. The external W3ID verifier checks 14 live HTML/Turtle routes and requires the permanent post-migration identifiers.

## Release bundle

The GitHub Release attaches the combined RDF distribution and the five authoritative ontology module files. The immutable Git tag also provides a stable repository snapshot for documentation, provenance, and future versioned W3ID routes.

## Publication boundary

Unversioned W3ID identifiers remain the stable current semantic/publication routes. Versioned W3ID module/distribution routes may be activated only against immutable targets derived from this governed release; they must never be redirected to mutable `main` content.
